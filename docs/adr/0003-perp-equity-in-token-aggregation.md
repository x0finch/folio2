# perp 权益(保证金)进代币聚合,并标注为保证金

永续账户的权益行(如 Hyperliquid 的 USDC 抵押)承载账户净值(仓位行在净值不变量下为 0),所以把它并入 USDC 的 Holding **按 value 不会重复计**,且契合"在各自的链、交易所**以及永续**里分别有哪些 USDT/USDC"的目标。这有反直觉之处 —— 保证金不是可自由动用的现货 —— 故每个这类 HoldingSource 明细行**标注「保证金」**。

## Consequences

- perp **仓位行**(衍生品敞口,value=0)与 **DeFi 仓位**(价值语义不可加)**不进**聚合,归入总览的「DeFi & 永续」次级分区。
