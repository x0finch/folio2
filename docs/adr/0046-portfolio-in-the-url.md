# 选中的 Portfolio 进 URL:查询参数 + push,默认那个不写

[ADR 0043](0043-in-page-tabs-in-the-url.md) 把「页内 tab 算不算『你在哪』」这条判据立了起来:算的进 URL,不算的留在 `useState`。**选中的 Portfolio 是这条判据下最明显的「算」** —— 它决定屏幕上这些钱是谁的钱 —— 而它至今只活在 `use-portfolio.tsx` 的 `useState` 里:硬刷新回默认,链接分享出去看到的是别人的默认组合,后退键撤销不了刚才那次切换。

**决定:选中的 Portfolio 进 URL,`?portfolio=<id>` 声明在 `_authed` 上;默认那个不写进 URL;切组合走 `push`;URL 是唯一事实源。**

## 为什么是查询参数,不是 `/{-$portfolioId}/…`

路径形态试过两轮,它有一个真优势:`to` 导航默认**不继承** search,于是「切组合把属于旧组合的参数丢掉」是免费的,而查询形态的默认是「全都带着走」、要显式清。

但三条压过它:

- **链接漏带参数不是编译错误。** 可选段(`{-$portfolio}`)省略本来就合法 —— 那正是它可选的意思 —— 所以侧栏、dock、任何程序化跳转忘了 `params: true` 就静默掉回默认组合,类型检查不管。查询形态用官方中间件 `retainSearchParams(["portfolio"])` 集中保留,**没有地方可忘**。
- **`/settings` 在段外,逛一趟就掉回默认。** 它不按组合 scope,所以不该进那个段;而从 `/settings` 点回账户页时,链接身上没有参数可带。要么让一个用不到组合的页面也背上这个段,要么接受「改个设置回来组合变了」。
- **好看这个动机不成立。** URL 里放的是 uuid(名字会被改名断链、还要一套 slug 唯一性与保留字校验),而 `/8f2c1a3e-…/accounts` 比挂在末尾的 `?portfolio=8f2c…` 更抢眼。

## 为什么这里用 push,而 tab 用 replace

看着矛盾,其实是同一条判据的两侧。ADR 0043 拒绝 `push` 的理由是「系统返回键变成倒放我刚点过的每一下」—— 那说的是**同一套数据换个看法**(代币 / 永续 / DeFi),换得频繁、每一下都不值一条历史。

**换组合换的是整套数据**,频率低、后果大,后退键撤销它符合直觉。两处不一致是**刻意的**,判据是「这一下换的是看法还是换了看的对象」。

## 切组合 = 一份全新的 search

只留 `portfolio`,`tab` / `token` / `account` / `focus` / `dim` 一律不带。

前四个装的都是旧组合里的具体东西(pin id、token id、账户 id),带进新组合是无意义或静默空白。`dim`(Insights 的分布维度)与组合无关,本可以留 —— 但**不留的规则更短**:「切组合就是从头开始」不需要维护一张「哪些该留」的清单,而每加一个新参数都要有人回来判一次的清单是会烂的。

**这条规则住在 `select()` 里,只管人手切组合。** 同步面板点某一行跳转到另一个组合的账户时,它自己一次 navigate 同时带 `portfolio` 和 `focus` —— 那个参数是故意的,不是残留。

## 落地时几处不显然的地方

- **`stripSearchParams` 帮不上。** 它只收静态默认值(`true` / key 数组 / 默认值对象),而「哪个组合是默认」是每用户的运行时数据。所以抹默认值这一步只能写在 `select()` 里 —— 好在它是唯一调用点。
- **`retainSearchParams` 不会把刚抹掉的值填回来。** 它只在「新 search 里没有这个 key」时补,并且带 `explicit` 元数据;显式写 `portfolio: undefined`(切回默认)能活下来。这两条规则因此可以同时成立,已核过实现。
- **`_authed` 的 loader 在切组合时不会重跑。** match id 是 `route.id + interpolatedPath + loaderDepsHash`,而 `cause = previousMatch ? "stay" : "enter"` —— 布局路由的 interpolatedPath 不含这个参数,所以它恒为 `stay`。于是那个 `await`(它替页头同步块挡首屏挂起,那块**没有自己的 suspense 边界**)只在 `cause === "enter"` 时等,切组合不阻塞。
- **四处预取的 key 写死了 `defaultId`**:`_authed` 的同步摘要、首页的 tab strip / 总览 / 24h 盈亏 / 历史、Insights 的总览与历史。今天这么写恰好是对的 —— 因为选中态**总是**从默认开始;URL 一旦能说别的,这四处必须读 URL,否则硬加载一个非默认地址会预取错的那份、组件再各自去拉一遍。这是「不改就静默慢一拍、没人会报 bug」的那种错。
- **切组合回顶部,不传 `resetScroll: false`。** 与 tab 相反是有理由的:tab 换的是同一套数据的视角,停在原处仍然有意义;组合换掉整套内容,旧的 y=600 在新组合里不代表任何东西,还可能落在空白里。
- **打开干净的 `/` 仍然回默认组合。** URL 是唯一事实源,不上 cookie —— 「记住我上次选的」是另一件事,要做就是另一片,而且要先想清楚它和 URL 谁说了算。
