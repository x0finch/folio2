# 桌面常驻左侧栏 + 移动 dock(逆转「弃常驻左栏」)

Folio v2(minimal)设计简报把导航定为桌面常驻左侧栏;同时每页头改为承载页标题 / 副标题 / 同步状态,腾空了原顶栏,自然让位给一条常驻左栏放导航 + 身份展示。据此**逆转**早期「桌面 / 移动统一顶栏 + dock、刻意弃常驻左栏」的决策(见 `apps/web/src/components/app-shell.tsx` 旧注释),改为**响应式二分**:桌面常驻左侧栏,移动端保留 dock(设计也保留)。

> **更新(#112,2026-07-19)**:侧栏 footer 收敛为**纯身份展示**;主题 / 语言 / 币种 / 登出等全局开关从外壳(侧栏 footer + 移动顶栏)撤出、统一落到 Settings 页。外壳只做导航 + 身份。

## Considered Options

- **维持顶栏 + dock(现状)** —— 不合 v2 设计。
- **桌面也纯 dock** —— 桌面信息密度与直达性不如常驻栏,不合设计。

## Consequences

- 桌面正文可用宽度减少约 236px。
- 维护两套导航范式(侧栏 + dock)。
- ⌘K 启动器与问候语一并移除,对齐 minimal(设计未含)。
